# Research Paper Docs — AI Suturing & Surgical Skill Quality Assessment

Literature package for the REU project *"Framework for Artificial Intelligence in
Quality Control of Suturing Among Undergraduates and Dermatology Residents"*.

## How the list was compiled

- Sources: PubMed (E-utilities), Semantic Scholar, Europe PMC, Crossref, publisher sites.
- Inclusion: peer-reviewed original studies, reviews, and systematic reviews published
  **2024–2026** aligned with the project scope — AI/computer-vision/deep-learning
  assessment of suturing and surgical skills, objective skill metrics (OSATS/GOALS/
  LS-CAT), automated feedback, and technology-enhanced surgical education.
- Each paper's methodology / pros / limitations in the Excel are grounded in the
  paper's published abstract and study design.
